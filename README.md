# מספר 8 — כדורגל תשיעיות

אפליקציית PWA בעברית: תרחישים טקטיים לילדים שמשחקים תשיעיות.
עובדת אופליין במלואה — פונטים, אייקונים ודיאגרמות מקומיים, בלי תלות ברשת אחרי הטעינה הראשונה.

## מבנה

```
index.html              תבנית התצוגה (בלי תוכן)
css/app.css             העיצוב
js/pitch.js             ציור המגרש — משותף לתצוגה, לעריכה ולתמונות מוקטנות
js/store.js             התקדמות על המכשיר
js/app.js               טעינה, ניווט, חיווט
content/booklets.json   רשימת החוברות
content/formations.json מערכים ומיקומי ברירת מחדל לפי מספר חולצה
content/kesher-8.json   חוברת: כותרת, תרחישים, תרגילים
fonts.css fonts/ icons/ manifest.webmanifest sw.js
```

## הרצה מקומית

הקבצים נטענים ב-`fetch` וב-ES modules, ולכן פתיחה ישירה של `index.html` מהדיסק לא תעבוד.
צריך שרת מקומי:

```bash
python3 -m http.server 8000
# ואז http://localhost:8000
```

## הוספת תוכן

**תרחיש** נוסף למערך `scenarios` בתוך קובץ החוברת. שדות:

| שדה | משמעות |
|---|---|
| `id` | מזהה קבוע וייחודי בחוברת. ההתקדמות של הילד נשמרת לפיו — **לא לשנות אחרי פרסום** |
| `phase` | שלב המשחק: `החזקה` · `הגנה` · `מעברים` (קובע את צבע הנקודה בצ'יפ) |
| `chip` / `title` / `sub` | כותרת קצרה לצ'יפ, כותרת מלאה, ותת-כותרת |
| `pos` | מיקומי שחקנים לפי מספר חולצה. מי שלא מופיע — במיקום ברירת המחדל מ-`formations.json` |
| `ball` | מיקום הכדור |
| `ghosts` | נקודות התחלה של תנועה (עיגול מקווקו) |
| `arrows` | `run` ריצה · `pass` מסירה · `opt` אפשרות · `press` תנועת יריב. `bend` מכופף לקשת |
| `zones` / `shadow` | הדגשת אזור או צל כיסוי |
| `does` / `mistake` / `cue` | הטקסט בפאנל |

מערכת הצירים היא `viewBox="0 0 400 620"` — השער שלנו למטה, מתקיפים כלפי מעלה.

**חוברת** חדשה: קובץ JSON ב-`content/`, ורישום שלו ב-`content/booklets.json`.
אפשר לבדוק אותה עוד לפני שהיא ראשית, עם `?b=<id>` בכתובת.

`role` בחוברת קובע איזה שחקן מודגש בוורוד — הדיאגרמות מתארות תפקיד מסוים,
ולכן ההדגשה נגזרת מהחוברת ולא מהגדרה גלובלית.

## מטמון וגרסאות

- **תוכן** (`content/*.json`) מתעדכן לבד. אין צורך לגעת ב-`sw.js` אחרי הוספת תרחיש.
- **קוד** (HTML/CSS/JS) נשמר cache-first. אחרי שינוי קוד יש להעלות את `SHELL` ב-`sw.js`
  (`kesher8-shell-v2` → `v3`), אחרת מכשירים שהתקינו ימשיכו לראות את הגרסה הישנה.
